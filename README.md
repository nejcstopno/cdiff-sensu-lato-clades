# *Clostridioides difficile* sensu lato — thirteen divergent clades

Analysis code, derived tables and figures for the manuscript
**"*Clostridioides difficile* sensu lato: thirteen divergent clades with labile toxin loci
and almost no conjugative transposons."**

## What this repository contains

| path | contents |
|---|---|
| `doc/manuscript.md` | manuscript source |
| `doc/detailed_methods.md` | per-analysis methodology, including pre-registered interpretation rules, negative controls and the limitations carried into the manuscript |
| `tables/` | 132 derived tables (CSV) |
| `figures/` | 31 figures (PNG + PDF) |
| `scripts/` | SLURM submission scripts for the cluster steps |
| `MANIFEST.csv` | every file with its size |

## Scope of the analysis

- **30,970** quality-passed *Clostridioides* genome entries = **29,455** unique strains.
- A **460-genome working set** (205 divergent + 255 one-per-PopPUNK-cluster comparators) reducing to **431 unique strains**.
- **Thirteen divergent clades** (DC1–DC13) below an empty 97–98% ANI band.

## Reproducibility status

`scripts/` now contains **53 pipeline scripts covering the full analysis**, recovered from
the compute cluster and renamed with a numeric prefix reflecting execution order, from
sourmash sketching of all 30,970 genomes through to the clade-specific primer design.
`scripts/_original_filenames.tsv` maps each to its original name on the cluster.

`scripts/_superseded_iterations/` holds 31 earlier versions of the same steps — PopPUNK
passes 1-4, the first KOfam and geNomad runs, the pre-outgroup dating scripts, and the
TreeTime fix iterations. **None contributed to a published result**; they are kept only so
the development path is traceable.

The ColabFold structural-modelling scripts from 27 October are deliberately excluded: that
phase was halted before completion, its outputs were never validated, and it is excluded
from the manuscript and all supplementary material.

**Software versions** are listed in `doc/detailed_methods.md` §33. Database paths in the
scripts are specific to the NLZOH cluster and must be repointed to run elsewhere.

Two large intermediates are **not** deposited and are regenerated by the scripts: the
Panaroo `gene_data.csv` (2.3 GB, from `08_panaroo_460.sb`) and the primer BLAST hit table
(156 MB, from `32_clade_specificity_leak.sh` and the primer design steps).

A complete archive of scripts **and final outputs** (7.6 GB, 346 files) is held on the NLZOH
storage volume at
`/volumes/homehpc/storage/finished_projects/NejcS/NLZOH/Cdiff_divergent_clades_2026/`.
